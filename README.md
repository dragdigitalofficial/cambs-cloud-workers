# Cambridgeshire Cloud Worker Runners

Distributed headless worker runner for the Cambridgeshire local business collector.

## Required GitHub Repository Secrets
Configure these secrets in **Settings -> Secrets and variables -> Actions**:
- `WASMER_SITE` (optional, defaults to `https://cambs-collector.wasmer.app`)
- `WASMER_WORKER_ID`
- `WASMER_WORKER_TOKEN`
